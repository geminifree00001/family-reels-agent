# 가족 릴스 에이전트 v6 — 사용법

## 설치
1. 이 압축을 `C:\Users\chris\Desktop\에이전트 실습 폴더`에 푼다. (기존 v3 폴더는 지워도 된다)
2. 폴더 안에 update.bat, AGENT.md, keywords.txt, README.md, VERSION이 있는지 확인한다.

## 실행 방법 (영상 찾기)
1. Muse 채팅을 연다.
2. 이렇게 말한다: "가족 릴스 에이전트 실행해줘"
3. Muse가 인스타에서 해외 가족 영상을 검색해서 댓글 많은 순으로 정리하고, 댓글 반응 분석 + 제목/첫 멘트까지 제안해준다.

## 업데이트 방법 (v4 신규)
- 새 버전이 나오면 `C:\Users\chris\Desktop\에이전트 실습 폴더` 안의 `update.bat`을 더블클릭한다.
- 끝. zip을 다시 받을 필요가 없다.
- 검은 창에 local 버전과 latest 버전이 표시되고, 다르면 자동으로 최신 파일로 덮어쓴다.
- `update.bat` 자체는 절대 바뀌지 않으니 안심하고 실행해도 된다.

## 키워드 바꾸기
- `keywords.txt`를 메모장으로 열어서 영어 키워드를 추가/삭제한다.
- 저장 후 다음 실행부터 반영된다.

## v6 변경점
- 댓글 분석 방식 명시: 원본 영어 영상 직접 해석·대본 재작성 금지 — 외국어 댓글 반응 분석으로 핵심 공감대 추출
- 공감 포인트 분석을 한국어로 요약 (예: "폭풍 공감과 유머: 나도 이런 적 있다", "현실적인 모녀/부부 티격태격 일상")
- 첫 멘트(TTS) 도출 규칙 강화: 댓글 분위기 기반 호기심 유발형 '~라는데' 문장 (예: "엄마랑 딸이랑 평생 안 맞는 이유라는데...", "결혼 10년 차 남편들이 절대 못 참는 순간이라는데...")

## v5 변경점
- 바이럴 키워드 체계 학습 반영 (가족/육아 유머, 부부 공감, POV 상황극, 돌발 상황) — keywords.txt 22개로 확장
